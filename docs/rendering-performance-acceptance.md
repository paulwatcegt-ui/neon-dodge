# 渲染性能第一轮：重复物件批量绘制

## 交付

- 新增 `src/rendering/projectileBatch.js`：普通弹丸使用一个固定容量96的InstancedMesh，保留原球体分段、半径、颜色、高度与世界坐标插值；不修改模拟数组、实体ID或碰撞。动态实例关闭视锥剔除，避免移动弹丸使用过期包围球而消失。
- 只更新有效实例数量；弹丸减少、复位和死亡后不会残留旧实例。区域/近战/冲锋继续使用原有环形显示。预热包含实例化弹丸材质；销毁释放实例GPU缓冲、几何与材质。
- 八边形40个重复静态物件合并为5组：8标记、8灯柱、8灯条、两组各8护栏。保留变换与材质，静态共享几何。场景销毁补充实例缓冲释放。
- 截图检查时发现390px宽窗口中能量/冲刺状态挤压，窄屏标题和值改为上下排列，并给敌人图例留出间距。没有加入移动端触控操作。

## 自动化与实际检查

- 49项Node测试通过：新增弹丸插值、区域过滤、容量上限、空池/复位、预热恢复、销毁事件、场地所有实例变换及混合威胁生命周期测试。原有玩法与帧率独立性测试通过。
- 全量11项浏览器测试通过，包含新增真实WebGL对照：同一视角96个独立球体为96次draw，实例化为1次draw，三角面数一致；20次清空/重填后几何数量稳定，销毁后几何为0。
- 窄屏布局调整后，再跑移动/窄屏/许可证/批量绘制4项针对性回归，全部通过；最新窄屏截图已检查，能量与冲刺读数不再互相挤压。
- 生产及测试子路径构建成功。主chunk约650kB，gzip约168kB；既有500kB提示仍保留，本轮优化的是运行时绘制提交，不是下载包体。
- 实际5180地址，1440×1000、均衡画质、T-00、开局tick20抽样：运行中、无JS异常，67次draw、1304三角面、37几何体、17纹理。此前Phase 4A记录为102次draw、1304三角面、72几何体、17纹理；计数变化与静态批量合并减少35次draw一致。桌面和窄屏截图已查看。

这些是功能与绘制计数验证，不是受控GPU耗时/帧率基准。未测试真实ND-01、峰值骨骼动画和纹理内存，不能据此承诺稳定60FPS。后续仍需目标Windows/GPU上的长时间试玩与帧时间测量。
