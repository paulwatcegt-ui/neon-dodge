# NEON DODGE

独立 Vite + Three.js + 原生 JavaScript 无限生存游戏。当前为可试玩平衡版 `balance-2.0.0`：放大的固定2.5D竞技场、八种敌人、E键主动防御脉冲；三格生命耗尽才结束，标准挑战与自适应练习分榜。保留机械体、泛光、动作反馈、合成音效和本地GLB/动画预览。

当前角色是本工程原创程序化临时机械体T-00，不能视为最终ND-01。真实ND-01 GLB/动画、素材授权核验及目标硬件性能验收仍待完成。未部署。

## Windows 本地运行

使用 Node.js 24.15 或以上兼容版本，以及 npm。在本项目目录运行（不要在父目录或 assessment 中安装）：

```powershell
npm ci
npm run dev
```

浏览器访问终端显示的 `http://127.0.0.1:5180/`，点击“开始测试”。默认使用5180避免与其他项目的5173冲突；端口占用时明确报错，不会自动切换端口。停止服务用 Ctrl+C。

如果环境只有 Node、没有 npm，可选用项目内工具，不需要全局安装或改系统 PATH：

```powershell
node scripts/bootstrap-npm.mjs
node .tools/package/bin/npm-cli.js ci --cache .npm-cache
node .tools/package/bin/npm-cli.js run dev
```

bootstrap 从官方 npm registry 下载固定 npm 12.2.0，并核对元数据中的 SHA-512。工具和缓存均保存在被忽略的工程子目录。

## 操作

| 操作 | 输入 |
|---|---|
| 移动 | WASD，屏幕方向，斜向速度归一化 |
| 冲刺 | Space 按下沿，默认朝上或沿最后移动方向 |
| 主动脉冲 | 满100能量后按 E，仅按下沿触发 |
| 全屏 | 顶部全屏按钮，进入或退出都会暂停，之后手动继续 |
| 暂停 / 恢复 | Esc，或页面按钮 |
| 复位 | 运行中的“复位”按钮 |
| 调试读数 | 展开右上角“遥测” |

冲刺持续12 tick（0.20秒），冷却96 tick（1.60秒，从起手计算），速度16单位/秒，无遮挡距离3.2单位；步行6单位/秒。冲刺撞墙即停，步行沿墙滑动。所有计时均为固定60Hz模拟。参数见 `src/config/gameplay.js`。

固定正交斜俯视相机不跟随玩家移动。画布有独立游戏视口，桌面HUD位于两侧与上下保留区；常见16:9桌面上竞技场投影包围框的长轴占可用游戏视口约75%–85%，不是整屏面积比例。顶部压缩至52px，桌面底栏54px；窄屏使用独立布局。全屏由浏览器授权，失败时保留普通窗口，不修改任何系统设置。

## 核心战斗

八类敌人使用独立AI模块；所有攻击先预警，伤害判定仍走统一连续碰撞管线。普通接触不造成伤害。

| 类型 | 外形/颜色 | 行为 |
|---|---|---|
| 追猎者 | 粉色方块 | 近身后36 tick蓄力，沿已锁定朝向打击 |
| 射手 | 橙色八面体 | 保持距离，42 tick瞄准后发射弹丸 |
| 冲锋者 | 紫色三角锥 | 48 tick锁定预警，沿固定方向冲锋30 tick；撞墙停止 |
| 封锁者 | 黄色六边柱 | 标记玩家当前位置，60 tick后形成半径1.4单位危险区，最多持续48 tick |
| 散射无人机 | 青色环体、三根炮管 | 54 tick三射线预警后发射±20°三向扇形弹幕，速度9 |
| 狙击无人机 | 红色长炮、瞄准镜 | 90 tick明显红色走廊预警，锁定同一方向后每8 tick射击一次，共3发，速度14 |
| 环绕无人机 | 蓝色多面体、斜环 | 连续环绕90 tick后停下，48 tick侧向瞄准，发射速度10的弹丸 |
| 爆裂无人机 | 亮绿装甲体、引信 | 接近至2.5单位后停止，60 tick圆环预警，半径2爆炸持续12 tick |

普通射手及环绕弹丸速度10单位/秒，散射9，狙击14。无人机弹丸按种类着色，仍共享一个容量96的实例池。参数入口见 `src/config/combat.js`、`src/config/enemies.js`、`src/config/difficulty.js`。

- 冲刺开始后前9 tick（0.15秒）与弹丸发生有效接触时触发完美闪避，抵消该弹丸并获得25能量。窗口采用半开区间，恰好0.15秒的接触不算完美。空地冲刺不奖励。
- 擦过角色外侧0.25单位区域并离开时获得10能量；在危险区停留不反复加能，先擦边再命中时优先结算命中。
- 每枚弹丸最多奖励一次。已经结算擦弹的弹丸不能再次触发完美奖励，但若玩家后来主动撞上，仍会受到伤害，避免利用奖励状态获得无敌。
- 达到100能量后可一直保留，按E才消耗100并释放半径4单位防御脉冲。它清除范围内威胁，附近敌人瘫痪90 tick（1.5秒），打断蓄力、冲锋及剩余狙击连射；蓝色光环表示瘫痪，恢复后必须重新蓄力。范围外敌人和已射出的范围外弹丸保留。脉冲不击杀、不计分、不续连击、不返能。
- E在本模拟步移动后、敌人更新与碰撞前结算，因此及时施放可以挡下即将发生的命中。若E按下时不足100，本步不扣能量；同一步稍后擦弹充满也不会补触发，需要重新按E。长按重复、设置控件输入、暂停和失焦都不会缓存一次未来释放。
- 三格装甲，每次命中扣一格，受伤后保护45 tick；普通受伤保护不提供闪避奖励。三格耗尽进入训练结束，按钮或Esc可重新开始。
- 威胁不只包含弹丸：近战、冲锋、区域攻击也能在有效窗口被完美闪避；接触时该次威胁被抵消，同一威胁不重复奖励或伤害。近战/区域威胁自然到期也会结算已满足条件的擦边。

## 单局、难度与计分

没有时限或自动胜利，HUD显示已生存的正计时。开局同时面对射手和追猎者。默认标准挑战使用统一固定曲线，受伤不降低压力；模式仅能在准备或结算页切换，对局中和暂停时不可切换。

| 阶段 | 时间 | 常规新增敌种 | 敌人上限 | 攻击准备/冲锋并发上限 |
|---|---|---|---:|---:|
| 交火 | 0–15秒 | 追猎者、射手 | 8 | 4 |
| 突进 | 15–35秒 | 冲锋者 | 12 | 5 |
| 扇形封锁 | 35–65秒 | 封锁者、散射 | 16 | 6 |
| 狙击交火 | 65–120秒 | 狙击 | 20 | 7 |
| 侧翼包抄 | 120–180秒 | 环绕 | 24 | 8 |
| 爆裂围攻 | 180–240秒 | 爆裂 | 24 | 8 |
| 无限高压 | 240秒以后 | 八种组合，每20秒切换侧重 | 24 | 8 |

刷怪基准间隔依次为60/54/46/40/36/34/32 tick，240秒后每60秒减1 tick，最多再减5，任何模式均不低于30 tick。刷怪与玩家至少相距5单位。各类名额：追猎10、射手4、冲锋4、封锁2、散射3、狙击2、环绕3、爆裂3；全体仍最多24，威胁最多96，起手会预留散射/狙击的3发容量。无安全生成位置时跳过。阶段移动速度最高1.3倍，前摇不随阶段缩短，恢复时间最低30 tick。

高压循环“猎杀推进 / 扇形狙击 / 侧翼围堵”，影响新敌人选择和存量敌人的恢复时间。满员且缺少已解锁类型时，每10秒至多轮换一名非攻击、非瘫痪的重复类型单位，新单位仍从安全位置入场，不奖励分数。起手至少隔12 tick，调度轮换优先级；冲锋/封锁/散射/狙击/爆裂的准备或攻击及活动封锁/爆炸区合计最多2个，同一时刻最多一个封锁区或其前摇。冲锋预警终点和速度锁定，跨阶段不突然加速。高危起手检查24个步行撤离位置，至少保留两个相邻位置才获准；它是离散保护，不能证明所有未来走位都可无伤，仍需真人针对墙角交叉火力试玩。

仅“自适应练习”叠加基于表现的动态压力，左下角显示模式与压力：

- 受伤后下一模拟步开始缓冲：刷怪间隔为阶段基准的1.4倍，敌人上限降为75%向下取整（至少3），攻击准备/冲锋并发上限减1。已有敌人和攻击保留，不取消预警或威胁；切换时延后下一次刷怪。
- 每5秒模拟时间复核一次，通常切换后至少保持10秒。受伤可立即覆盖强化；最近15秒受伤或仅剩1格生命时保持缓冲。无近期受伤后可回到标准。
- 满血、开局至少15秒，近期记录包含至少2次完美闪避且完美+擦弹至少8次时，进入强化：刷怪间隔为基准的85%并四舍五入到整数tick；不增加阶段敌人/并发上限。近期表现按1秒桶收集，保留最近15个秒桶，闲置存活、击杀和分数不计作闪避表现。
- 三种压力均不改变敌种解锁、攻击前摇、移动/弹丸速度、冲刺参数、0.15秒窗口或得分公式。暂停冻结统计，重开清空；所有统计只在本地模拟内使用。

动态压力历史记录见 `docs/adaptive-difficulty-acceptance.md`，当前平衡版以 `docs/balance-2-acceptance.md` 为准。

完美闪避基础100分、擦弹20分，成功闪避事件累积连击，每5次提高0.5倍倍率，最高4倍；3秒无新闪避或受伤清空当前连击，保留本局最高连击。主动脉冲和敌人轮换没有任何分数收益。存活每秒10分，不乘连击倍率；没有胜利奖金。

结束页显示得分、最高连击、存活时间、完美次数和本模式最高分。仅生命耗尽后保存到 `neon-dodge.records.v2.balance-2.0.0`，标准/练习各保留前10名；旧v1及原无限版v2键均保留，不迁入新榜。复位、切模式、暂停、失焦不结算。每局生成新UUID与32位种子；记录含规则版本、模式、分数、生存tick/秒、完美/擦弹、最大连击、ID及种子。存储失败降级到内存；没有服务器或自动上传。结构与未来服务端边界见 `docs/score-record-schema.md`。

战斗参数见 `src/config/combat.js`。这是第一轮手感参数，尚需真人试玩调节。

## 视觉、音效与模型导入

右上角“设置”可以切换画质、关闭音效、减少粒子/震动，并导入本地GLB。打开设置会暂停对局；关闭后需要手动继续。按键焦点位于设置控件时，不向游戏发出移动或冲刺指令。

- 流畅：不使用Bloom，关闭阴影，像素比最多1。
- 均衡：Bloom与阴影，像素比最多1.5。
- 精细：保留Bloom与阴影，像素比最多2；实际比例仍不超过设备像素比。
- 粒子、轨迹、震动基于模拟tick，暂停时冻结，复位清空；死亡动画属于结算后的纯显示效果。
- Web Audio音效只在用户点击开始/继续后解锁；支持静音，暂停停止当前音效。没有外部音频下载。
- 设置默认不持久保存，刷新后恢复默认；减少动态效果初值尊重系统偏好。

GLB导入只在浏览器内存中预览，不上传、不写入工程，也不会在刷新后保留。最大30MB，当前支持glTF 2.0单文件内嵌几何/贴图；外部纹理/二进制引用、Draco/Meshopt/KTX2压缩会明确拒绝，待实际资产需要时再接解码器。

导入后自动统一脚底、水平中心及1.7单位高度，保留PBR材质，显示三角面/材质/骨骼数量。可按90°步进修正朝向。匹配idle/stand、run/walk、dash/dodge/roll、hit/hurt/damage、death/die等动画名并做混合；缺失动作会列出，不生成缺失动画、不做骨架重定向。源模型应使用原地动画；当前不会自动提取或移除骨盆root motion。碰撞半径和所有玩法数值不随模型改变。

加载失败保留当前角色；恢复按钮释放导入模型并切回T-00。单模型超过10万三角面或16材质会提示优化，但这只是初始预算提醒，不代表真实设备性能保证。展开遥测可以查看整帧绘制调用、三角面、几何体和纹理数量（不等同于GPU内存字节数）。

场地的40个护栏/灯柱/灯条/标记合并为5组实例化绘制；普通弹丸共享一个容量96的实例池，满池仅需一次绘制。区域、近战和冲锋威胁仍按各自形状显示。实例化只影响显示，不改变模拟、预警、碰撞或闪避判定；验证与实测计数见 `docs/rendering-performance-acceptance.md`。

窗口失焦/标签隐藏时暂停，清空输入；回来后手动恢复。大于约100ms的单帧模拟积压会触发性能暂停，避免跳过碰撞。其目标是保证原型判定可靠，不代表已经完成低端硬件性能优化。

## 验证

```powershell
npm test
npm run test:e2e
npm run build
npm run preview
```

浏览器测试在 Windows 默认使用已安装的 `C:\Program Files\Google\Chrome\Application\chrome.exe`。其他位置可设置 `CHROME_PATH` 环境变量；无系统 Chrome 时可安装 Playwright 对应 Chromium。浏览器下载不是运行游戏的依赖。

`test:e2e` 自动构建到 `test-results/site/`，在 `/neon-dodge/` 子路径启动临时生产服务器，同时在5181启动临时开发服务器，验证CSS加载和真实3D启动；检查完成后关闭两者。截图在 `test-results/`。普通构建输出到 `dist/`，默认相对 base 可用于静态子路径，发布时上传 dist 内容即可。`preview` 仅用于本地验证。

生产默认无调试全局；显式添加 `?diagnostics=1` 可启用只读 `window.__ND.snapshot()`。开发模式默认开启同一只读接口，无状态设置或作弊命令。

## 结构和边界

- `simulation/`：移动、连续碰撞、四类AI、威胁、能量/脉冲、计分和难度调度；无 Three.js、DOM、音频、现实时间依赖。
- `core/`：固定步长累积器、会话状态、暂停和重开。
- `input/`：按键状态、按下沿、失焦清理。
- `rendering/`：固定相机、统一竞技场几何、插值显示、资源释放。
- `ui/`：显示状态与提交操作请求。
- `storage/`：带校验与失败降级的本机记录，不参与模拟。
- `assets/`：GLB检查/解析、尺寸规范化、动画映射与资源释放。
- `audio/`：带手势解锁、静音和声部上限的程序音效。
- `vendor/voxel-survivors/rng.js`：明确来源的 MIT 工具，用于可重复刷怪与碰撞压力测试，每局独立种子。

没有复制原游戏 HTML、军阵、装备、据点、自动攻击、升级、统计服务或部署域名。许可证与代码来源见 `THIRD_PARTY_NOTICES.md` 和 `docs/reuse-manifest.md`。

当前规则验收见 `docs/balance-2-acceptance.md`，成绩结构见 `docs/score-record-schema.md`；此前阶段记录保留为历史。ND-01尚未提供，真实模型兼容性检查待素材到位；当前不承诺最终模型性能或移动端触控操作支持。
