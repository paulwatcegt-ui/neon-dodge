# Phase 4A：视觉、音效与模型接入管线

本轮完成可独立推进的视觉与模型基础部分。真实ND-01文件及动画仍未提供，不能将Phase 4的正式角色与模型性能验收记为完成。本次没有部署、下载商业美术资产或改变其他项目；没有新增npm依赖。

## 本轮交付

- 原创程序化临时机械体T-00，具有装甲、关节、头部面罩与发光部件，随模拟运动摆动。界面明确说明临时身份。
- 霓虹侧边、节点灯、金属场地、环境反射；同版本Three.js后处理提供轻量Bloom和输出色彩处理。
- 有上限的粒子128、冲刺轨迹16、已有环形池12；视觉随机采用hash01，不反馈到模拟。减少动态选项隐藏额外粒子/轨迹并禁用镜头扰动。
- 合成冲刺、完美、擦弹、脉冲、受伤和结算音效。手势解锁、暂停静音、手动静音、单tick最多3音、同时最多12声部；音频不可用时玩法继续。
- 流畅/均衡/精细画质，像素比上限1/1.5/2；流畅关闭Bloom与阴影。遥测新增完整渲染帧draw calls/triangles/geometry/texture计数。
- 开始前预热场景、攻击预警与后处理；初次增加Bloom曾触发100ms保护暂停，已通过准备阶段提前编译并绘制预热。准备完成前开始按钮禁用，避免误将编译时间计入游戏。
- 本地单文件GLB导入、头/块/版本/体积检查，外部资源与未接入的压缩扩展明确拒绝。失败保留当前角色，异步导入序号防止旧请求覆盖新选择，销毁时释放模型几何/材质/纹理/ImageBitmap与动画缓存。
- 尺寸/脚底归一化、PBR材质保留、90°朝向选项、五状态动画名称映射与混合、缺失动画报告。玩家碰撞与模型完全分离。

## 验证

41项Node测试通过：保留37项玩法测试；新增GLB损坏/外部引用/压缩拒绝、真实GLTFLoader解析与尺寸规范化、五动作识别/播放/零delta冻结/销毁、缺失动画报告及音效手势/暂停/静音验证。

9项浏览器测试通过，涵盖既有开发模式、生产子路径、真实输入与战斗，以及新增GLB文件选择→加载→动作识别→朝向/高低画质→减少动态→静音→错误模型回退→恢复临时角色的完整流程，未发现外部网络请求或JS异常。截图已检查桌面与窄屏。GLB夹具是本工程生成的小三角面，不代表真实ND-01测试。

另在用户实际5180地址以均衡画质启动确认：模式running、无JS异常；初始场景一次采样为102绘制调用、1304三角面、72几何体、17纹理。此为功能/计数检查，不是帧率或显存基准，也不是高峰战斗数据。

普通生产构建与子路径测试构建均成功；GLTFLoader按需加载为独立chunk。渲染主包仍大于500KB，记录其提示，不以调高阈值掩盖。实际构建大小以终端输出为准。
