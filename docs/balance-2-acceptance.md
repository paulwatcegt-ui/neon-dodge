## 画面与交互

- 竞技场使用固定正交相机，方向`(0,-0.75,-1)`，不跟随玩家移动。保留2.5D斜俯视、真实3D模型与灯光。按竞技场实际顶点拟合，常见16:9桌面投影包围框的长轴约占可用游戏视口75%–85%；这是轴向占用，不是整屏面积比例。
- 游戏画布避开上下HUD和两侧信息栏。桌面顶部52px、底部54px；窄屏顶部集中状态，底部106px，图例收起。边界完整保留，角色与预警使用原世界坐标，显示放大不改变碰撞半径或移动距离。
- 全屏按钮支持进入/退出，转换前暂停、清空按键、复位时钟；返回后手动继续。API不可用则禁用，拒绝请求则给按钮提示，不抛出未处理异常。
- 满能量提示为“E · 释放脉冲 / 4m”，非满能量显示不足提示。长按不连发，暂停/失焦清输入，在设置或表单中输入不触发技能。

240秒以后持续循环“猎杀推进 / 扇形狙击 / 侧翼围堵”，每20秒切换，改变存量敌人的恢复时间与新单位选择。刷怪间隔从60tick逐步降至32，240秒后的分钟阶梯也不低于30tick。整体敌人仍24、威胁96、攻击准备/冲锋/狙击连射最多8；起手间隔12tick，散射与狙击预留三发容量。无人机弹丸按种类着色，但仍单批实例化绘制。

敌人满员时，若有已解锁但缺席的类型，至多每10秒轮换一个非攻击、非瘫痪的重复类型；新单位仍需至少离玩家5单位且通过场地/重叠检查。不会删除进行中的攻击来腾名额，轮换没有分数与能量收益。无击杀的601秒测试也能见到八种敌人。

高危类型（冲锋/封锁/散射/狙击/爆裂）及其准备/连射、活动封锁/爆炸合计最多2；同一时刻只允许一个封锁区或其前摇。起手还需通过24方向步行撤离位置检查，至少保留两个相邻采样位置，不假设冲刺可用。所有新危险都先有线、扇形或圆形预警；狙击连射过程中走廊继续显示且不跟踪玩家。

上述是保守调度和离散位置检查，不是完整时空轨迹搜索，不能证明任意未来交叉弹幕或玩家走位都无伤可解。墙角、冲刺刚用完、狙击叠加爆裂/散射的组合仍是人工试玩重点。

## E键脉冲与结算顺序

满100不自动释放，E按下沿才消费100。半径4内清除威胁、敌人瘫痪90tick（1.5秒）并取消蓄力、冲锋及剩余连射；蓝色光环标明瘫痪。范围外单位和独立弹丸保留；被中断的附着冲锋威胁同步清除。恢复后重新起手完整前摇。

顺序为玩家移动/冲刺→主动脉冲→敌人更新→连续碰撞→计分/时间。及时施放可清掉即将致命的弹丸。按E时不足100不扣能；同tick后续擦弹才充满不会补发，需要再次按E。脉冲不击杀、不发分、不建立/续连击、不返能，消除了通过群体击杀放大分数的路径。每个威胁仍最多给一次擦弹/完美奖励。
