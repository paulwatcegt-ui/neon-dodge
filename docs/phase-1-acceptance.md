# Phase 1 验收

日期：2026-10-20（Asia/Shanghai）。范围：独立工程、灰盒移动、固定镜头、八边形碰撞、冲刺、暂停/复位、许可及本地构建。到本阶段停止，不进入敌人/战斗阶段。

## 自动化验证

环境：Windows，Node v24.19.0；Vite 8.3.4、Three.js 0.186.1、Playwright 1.64.1，使用本机无界面 Chrome。实际依赖锁定于 package-lock.json。

- 12项 Node 测试通过：8边扫掠、8角重复运动、行走滑墙与冲刺停墙、2万次种子随机压力测试、斜向速度、12步冲刺/48步冷却、冲刺方向锁定、旋转镜头方向转换、30/60/144Hz一致性、暂停与复位、长帧保护、按键边沿/失焦/销毁。
- 3项浏览器测试通过：真实D键/Space、Esc暂停/按钮恢复、失焦后清除按键、复位；390×844窄屏控件布局；生产子路径、许可文本与调试开关。
- 生产构建成功，输出dist/。浏览器测试另用带 `/neon-dodge/` 子路径的生产构建。
- 游戏页面浏览器测试未捕获到JS异常，未发现外部网络请求。
- 截图由测试保存，已检查桌面与窄屏画面；窄屏只做布局检查，不表示具备触控玩法。

## 已知限制

- 当前ND-01为灰盒占位，未验证真实GLB与动画。
- 敌人、完美闪避、擦弹、能量、生命/计分/连击、结算尚未实施，属于后续阶段。
- 未进行真人长时手感验收或真实GPU性能基准；无界面Chrome通过不代表目标设备稳定60FPS。
- 单JS包约547KB、gzip约139KB，主要为Three.js，Vite有500KB体积提示；本阶段记录该提示，后续加入模型时统一优化，不以调高阈值掩盖问题。
- 不支持手机触控移动；Windows键盘为本阶段目标。
- 首次环境只有Node、缺少npm。已在工程内下载校验npm；安装辅助工具的Windows包装路径不兼容，最终直接调用工程内npm CLI完成安装。没有改系统PATH或全局安装。
