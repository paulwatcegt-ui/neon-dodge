# NEON DODGE

Phase 4A：独立 Vite + Three.js + 原生 JavaScript 工程。完整180秒竞技生存核心，加上临时机械角色、霓虹舞台、泛光、动作反馈、合成音效和本地GLB/动画预览。

当前角色是本工程原创程序化临时机械体T-00，不能视为最终ND-01。真实ND-01 GLB/动画、素材授权核验及目标硬件性能验收仍待完成。未部署。

## Windows 本地运行

使用 Node.js 24.15 或以上兼容版本，以及 npm。在本项目目录运行（不要在父目录或 assessment 中安装）：

```powershell
npm ci
npm run dev
```

浏览器访问终端显示的 `http://127.0.0.1:5180/`，点击“开始测试”。默认使用5180避免与其他项目的5173冲突；端口占用时明确报错，不会自动切换端口。停止服务用 Ctrl+C。

如果环境只有 Node、没有 npm，可选用项目内工具，不需要全局安装或改系统 PATH：

```powershell
node scripts/bootstrap-npm.mjs
node .tools/package/bin/npm-cli.js ci --cache .npm-cache
node .tools/package/bin/npm-cli.js run dev
```

bootstrap 从官方 npm registry 下载固定 npm 12.2.0，并核对元数据中的 SHA-512。工具和缓存均保存在被忽略的工程子目录。

## 操作

| 操作 | 输入 |
|---|---|
| 移动 | WASD，屏幕方向，斜向速度归一化 |
| 冲刺 | Space 按下沿，默认朝上或沿最后移动方向 |
| 暂停 / 恢复 | Esc，或页面按钮 |
| 复位 | 运行中的“复位”按钮 |
| 调试读数 | 展开右上角“遥测” |

冲刺持续12 tick（0.20秒），冷却48 tick（0.80秒），速度24单位/秒；步行6单位/秒。冲刺撞墙即停，步行沿墙滑动。所有计时均为固定60Hz模拟。参数见 `src/config/gameplay.js`。

## 核心战斗

四类敌人使用独立AI模块；所有攻击先预警，伤害判定仍走统一连续碰撞管线。普通接触不造成伤害。

| 类型 | 外形/颜色 | 行为 |
|---|---|---|
| 追猎者 | 粉色方块 | 近身后36 tick蓄力，沿已锁定朝向打击 |
| 射手 | 橙色八面体 | 保持距离，42 tick瞄准后发射弹丸 |
| 冲锋者 | 紫色三角锥 | 48 tick锁定预警，沿固定方向冲锋30 tick；撞墙停止 |
| 封锁者 | 黄色六边柱 | 标记玩家当前位置，60 tick后形成半径1.4单位危险区，最多持续48 tick |

- 冲刺开始后前9 tick（0.15秒）与弹丸发生有效接触时触发完美闪避，抵消该弹丸并获得25能量。窗口采用半开区间，恰好0.15秒的接触不算完美。空地冲刺不奖励。
- 擦过角色外侧0.25单位区域并离开时获得10能量；在危险区停留不反复加能，先擦边再命中时优先结算命中。
- 每枚弹丸最多奖励一次。已经结算擦弹的弹丸不能再次触发完美奖励，但若玩家后来主动撞上，仍会受到伤害，避免利用奖励状态获得无敌。
- 达到100能量后，下一模拟步的碰撞结算完成后自动释放半径4单位脉冲，消耗100能量、击毁范围内敌人并清除威胁；不通过击杀返还能量。若同一步先受到致命伤，则取消释放。冲锋威胁在其拥有者被击毁后同时移除。
- 三格装甲，每次命中扣一格，受伤后保护45 tick；普通受伤保护不提供闪避奖励。三格耗尽进入训练结束，按钮或Esc可重新开始。
- 威胁不只包含弹丸：近战、冲锋、区域攻击也能在有效窗口被完美闪避；接触时该次威胁被抵消，同一威胁不重复奖励或伤害。近战/区域威胁自然到期也会结算已满足条件的擦边。

## 单局、难度与计分

单局180秒，完成全部阶段即胜利；生命耗尽即失败，同一最后模拟步发生致命伤时失败优先。开局保留一名引导射手，之后按阶段表生成敌人。

| 阶段 | 时间 | 常规新增敌种 | 敌人上限 | 攻击准备/冲锋并发上限 |
|---|---|---|---:|---:|
| 启动 | 0–30秒 | 追猎者 | 6 | 3 |
| 交火 | 30–60秒 | 射手 | 10 | 4 |
| 突进 | 60–100秒 | 冲锋者 | 14 | 5 |
| 封锁 | 100–140秒 | 封锁者 | 18 | 6 |
| 过载 | 140–180秒 | 四类组合 | 24 | 8 |

刷怪与玩家至少相距5单位，射手最多4名、封锁者最多2名，所有活动威胁最多96个。无安全生成位置时跳过该次生成。各阶段移动速度最高提升至1.2倍，攻击前摇不缩短。难度按时间推进，未加入按玩家表现调整的DDA。

完美闪避基础100分、擦弹20分、击杀150分。有效事件累积连击，每5次提高0.5倍倍率，最高4倍；3秒无新事件或受伤清空当前连击，保留本局最高连击。存活每秒10分，不乘连击倍率；胜利额外1000分及每格剩余生命250分。

结束页显示得分、最高连击、存活时间和本机最高分。仅自然胜负结算保存到 `neon-dodge.records.v1`；复位不结算。存储不可用或数据损坏时仍可继续游戏，使用内存记录；重开清空单局状态。记录只在本浏览器本来源内保存，没有网络排行榜。

战斗参数见 `src/config/combat.js`。这是第一轮手感参数，尚需真人试玩调节。

## 视觉、音效与模型导入

右上角“设置”可以切换画质、关闭音效、减少粒子/震动，并导入本地GLB。打开设置会暂停对局；关闭后需要手动继续。按键焦点位于设置控件时，不向游戏发出移动或冲刺指令。

- 流畅：不使用Bloom，关闭阴影，像素比最多1。
- 均衡：Bloom与阴影，像素比最多1.5。
- 精细：保留Bloom与阴影，像素比最多2；实际比例仍不超过设备像素比。
- 粒子、轨迹、震动基于模拟tick，暂停时冻结，复位清空；死亡动画属于结算后的纯显示效果。
- Web Audio音效只在用户点击开始/继续后解锁；支持静音，暂停停止当前音效。没有外部音频下载。
- 设置默认不持久保存，刷新后恢复默认；减少动态效果初值尊重系统偏好。

GLB导入只在浏览器内存中预览，不上传、不写入工程，也不会在刷新后保留。最大30MB，当前支持glTF 2.0单文件内嵌几何/贴图；外部纹理/二进制引用、Draco/Meshopt/KTX2压缩会明确拒绝，待实际资产需要时再接解码器。

导入后自动统一脚底、水平中心及1.7单位高度，保留PBR材质，显示三角面/材质/骨骼数量。可按90°步进修正朝向。匹配idle/stand、run/walk、dash/dodge/roll、hit/hurt/damage、death/die等动画名并做混合；缺失动作会列出，不生成缺失动画、不做骨架重定向。源模型应使用原地动画；当前不会自动提取或移除骨盆root motion。碰撞半径和所有玩法数值不随模型改变。

加载失败保留当前角色；恢复按钮释放导入模型并切回T-00。单模型超过10万三角面或16材质会提示优化，但这只是初始预算提醒，不代表真实设备性能保证。展开遥测可以查看整帧绘制调用、三角面、几何体和纹理数量（不等同于GPU内存字节数）。

窗口失焦/标签隐藏时暂停，清空输入；回来后手动恢复。大于约100ms的单帧模拟积压会触发性能暂停，避免跳过碰撞。其目标是保证原型判定可靠，不代表已经完成低端硬件性能优化。

## 验证

```powershell
npm test
npm run test:e2e
npm run build
npm run preview
```

浏览器测试在 Windows 默认使用已安装的 `C:\Program Files\Google\Chrome\Application\chrome.exe`。其他位置可设置 `CHROME_PATH` 环境变量；无系统 Chrome 时可安装 Playwright 对应 Chromium。浏览器下载不是运行游戏的依赖。

`test:e2e` 自动构建到 `test-results/site/`，在 `/neon-dodge/` 子路径启动临时生产服务器，同时在5181启动临时开发服务器，验证CSS加载和真实3D启动；检查完成后关闭两者。截图在 `test-results/`。普通构建输出到 `dist/`，默认相对 base 可用于静态子路径，发布时上传 dist 内容即可。`preview` 仅用于本地验证。

生产默认无调试全局；显式添加 `?diagnostics=1` 可启用只读 `window.__ND.snapshot()`。开发模式默认开启同一只读接口，无状态设置或作弊命令。

## 结构和边界

- `simulation/`：移动、连续碰撞、四类AI、威胁、能量/脉冲、计分和难度调度；无 Three.js、DOM、音频、现实时间依赖。
- `core/`：固定步长累积器、会话状态、暂停和重开。
- `input/`：按键状态、按下沿、失焦清理。
- `rendering/`：固定相机、统一竞技场几何、插值显示、资源释放。
- `ui/`：显示状态与提交操作请求。
- `storage/`：带校验与失败降级的本机记录，不参与模拟。
- `assets/`：GLB检查/解析、尺寸规范化、动画映射与资源释放。
- `audio/`：带手势解锁、静音和声部上限的程序音效。
- `vendor/voxel-survivors/rng.js`：明确来源的 MIT 工具，用于可重复刷怪与碰撞压力测试，每局独立种子。

没有复制原游戏 HTML、军阵、装备、据点、自动攻击、升级、统计服务或部署域名。许可证与代码来源见 `THIRD_PARTY_NOTICES.md` 和 `docs/reuse-manifest.md`。

实际验收与限制见 `docs/phase-4-acceptance.md`，此前阶段记录保留。ND-01尚未提供，真实模型兼容性检查待素材到位；当前不承诺最终模型性能或移动端操作支持。
