# ND-01 / PHANTOM 角色接入验收

本轮仅本地接入、测试，无提交、推送或部署；保留此前尚未提交的启动入口、全窗口布局、计时与光效调整。

## 素材与加载

- AETHER / 02，Ramon Linares，CC0。GLB 原样保存在 `public/models/aether-02.glb`，5992836 字节。固定来源提交、SHA-256、Git blob 标识及动画来源记录于 `public/models/README.md`，CC0 法律文本保存在 `public/licenses/aether-02-CC0-1.0.txt`。
- 24310 三角面、5 网格/材质、18 骨骼、4 张内嵌图片、11 动画。
- 扩展只有 `KHR_materials_clearcoat`、`KHR_materials_emissive_strength`，现有 GLTFLoader 支持。不含 Draco、Meshopt、KTX2，没有增加 npm 依赖、外部字体或在线模型请求。
- 主流程在初始预热前加载默认资产，使用 Vite BASE_URL 适配子路径部署。下载/解析失败回退 T-00，下载有15秒超时；恢复按钮重试默认角色。手动 GLB 导入、朝向修正及失败保持原角色继续工作。异步代次检查与释放避免晚到结果覆盖新模型。
- 保留原材质、颜色、贴图和自发光，没有额外强反应堆灯光。高度规范化为1.7单位，水平居中、脚底对齐；按原+Z前向跟随玩家朝向，圆形碰撞体不跟随骨骼变形。

## 动画兼容性

| 游戏状态 | 原动画 | 原长度 | 游戏播放 |
|---|---|---:|---|
| 待机 | Sentinel | 6秒 | 循环，1倍 |
| 跑步 | Run | 0.9333秒 | 循环，初始2倍 |
| 冲刺 | DodgeRoll | 2.8667秒 | 单次，压缩到0.20秒，约14.33倍 |
| 受击 | HitChest | 1.4667秒 | 单次，压缩到0.24秒 |
| 死亡 | Collapse | 3秒 | 单次，保持最后姿势 |

精确名称优先于通用匹配，避免误选 HitHead、Walk 等动作。翻滚进入/退出使用25ms短混合，其他状态约40–100ms。动画不延迟输入、控制位移或改变伤害/完美窗口。冲刺撞墙仍立即停下，动作可以提前退出。死亡动作在停止模拟后以渲染时间继续播放，暂停时普通动作冻结。

只对PHANTOM克隆动画并固定root水平通道，保留垂直翻滚/倒地动作，原始GLB不修改。运行时抬升混合后略穿地的显示模型，保留跑步原有腾空阶段，不将碰撞体抬起。加入柔和接地阴影；原实时阴影设置保留。

接地初版全顶点扫描偏贵，因此按此资产单骨骼刚性权重计算每骨骼凸包，保留3652个极值顶点。运行时仅采样这些顶点；若不是刚性权重，退回完整顶点检查。完整蒙皮边界独立对照五种动作及中间姿势，采样最低点未低于地面（约0.002单位余量）。

## 测试与性能

- 最终73项单元测试、20项浏览器测试通过，生产构建通过；同时验证子路径生产服务。原完美闪避、E技能、暂停、计分、榜单、无限生存与GLB导入测试保留并通过。
- 新测试覆盖默认加载/刷新、真实WASD跑步、下载503回退T-00和恢复、精确动画映射、200ms翻滚及单次死亡保持、真实材质/骨骼、动作中间接地、连续4次实际模型替换。
- 替换后几何体/纹理计数稳定，释放时关闭贴图、释放骨骼纹理、材质/几何体并注销AnimationMixer。此结果不是长时显存字节测试。
- 首轮仅一项测试失败：旧“无外部请求”断言将内嵌图片产生的同源blob URL视为外部依赖。只放行同源blob，其余外部地址继续拒绝，最终全量通过。
- 实际5180页，1600×900、均衡画质，本机一次从导航到就绪约2.99秒；真实按键运行、无JS错误。该采样在接地计算优化前完成，不作为网络冷启动或FPS承诺。
- 接地优化后独立本地加载/解析/初始化采样约1.14秒；300次动作采样的动画+接地中位1.6ms、P95约2.9ms。采样环境为自动化Chrome，本机测试；不等于整帧时间，也不证明高压60FPS。
- 构建主chunk约668kB，已有500kB提示仍在；模型增加约5.99MB静态资源，未隐藏提示。实际显存字节数、目标GPU长时高压及实体手机未验收。
