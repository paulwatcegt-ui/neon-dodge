# 无限生存规则 endless-1.0.0

本轮仅本地修改、测试和浏览器试玩；未提交Git、未推送、未部署、未引入依赖或在线服务。Three.js模块结构、T-00机械体、GLB/动画预览、四类AI、音效与特效保留。正式ND-01资产仍未提供。

## 玩法变化

- 删除180秒上限、自动胜利、胜利音效和胜利奖金，只有HP降为0结束。正计时与生存每秒10分无限推进，死亡后模拟、分数冻结。
- 开局2种敌人，1秒即开始补充；15秒解锁冲锋、35秒解锁封锁，65秒过载，120秒进入永久高压。上限分别8/12/16/20/24，刷怪间隔60/54/48/42/36tick；120秒后分钟阶梯最多再减5tick。各类攻击恢复时间降低，但原前摇36/42/48/60tick不缩短。
- 高压每20秒轮换猎杀/交叉火力/区域围堵；改变存量敌人的攻击恢复时间及新增敌人选择，满24个敌人仍变化。优先级按tick轮换，不让固定数组前几个敌人永久垄断起手。
- 冲刺距离3.2、冷却1.6秒、持续0.2秒，完美窗口仍0.15秒，撞墙提前停止。固定步长、连续碰撞和屏幕方向转换不变。
- 标准模式无受伤降压，练习模式沿用独立自适应逻辑；对局中和暂停时不允许改模式，死亡后或准备时可切换，成绩严格分榜。
- 仅完美/擦弹推进或续连击；脉冲击杀每只固定50分，不乘连击、不续连击、不返能，已移除敌人不重复计分。伤害清连击，每个威胁仍至多奖励一次。

## 公平性与容量

敌人24、威胁96、同时准备/冲锋8是硬上限，射手最多4、封锁者最多2。起手至少隔12tick，高危准备/冲锋/活动封锁区合计最多2，同时最多一个封锁区或其前摇。生成点离玩家至少5单位，找不到安全位置就跳过。

新增24方向步行可达位置检查：高危起手至少保留2个相邻未被现有/拟新增威胁覆盖的采样撤离点；不假设冲刺已冷却。若检查不通过，敌人等待重新起手。此检查是离散端点与危险走廊的保守筛查，不是完整未来轨迹搜索，不能保证玩家任何走位或任意交叉火力都可无伤；仍需真人针对墙角、刚用完冲刺时的交叉组合试玩。

冲锋的宽度1.0地面预警和中心线显示完整锁定路径；实际移动速度在前摇开始时锁定，即使跨阶段也不超出预警距离，墙体截断预警。测试包括斜向地面走廊的旋转方向，避免只画出了相反对角线。

## 测试方法与范围

- 全部Node测试，包括原碰撞、音效、GLB、渲染释放和输入测试；新增无限规则、跨600秒、模式切换、计分防重复、脉冲收益边界、撤离采样和成绩协议测试。
- 3个固定种子×标准/练习模式，真实逐tick推进至601秒，测试保护仅在夹具中写入，不向生产页面添加作弊接口。检查181/301/601秒仍running、各类容量有界、满敌人时战术继续轮换、后期仍发射攻击。此为加速模拟，不是玩家无伤存活601秒。
- 浏览器同时推进真实模拟、渲染与周期性脉冲清怪，检查181/301/601秒的几何、纹理、强制GC后JS堆；另组合24敌人+96弹丸渲染。保护和满能量仅位于测试独立路由中，正式`window.__ND`仍只有只读快照。
- 浏览器模式选择→前10名分榜→重开保留模式/换ID、三格死亡→完整结算→保存一次、暂停/失焦/复位、GLB错误回退与画质设置全部回归。旧胜利测试已改成600秒以后的死亡结算测试，未删掉对应功能覆盖。

最终执行结果：**58项Node单元测试、13项浏览器测试全部通过**，普通生产及静态子路径构建成功，`git diff --check`通过。源码与HTML已无RUN_TICKS、胜利状态或180秒终止逻辑；剩余测试中的victory仅用于断言不再发出胜利事件。未删改GLB、音效或视觉基础测试，已有计时/冲刺/死亡/旧存储测试按新规则更新。

浏览器回收后JS堆与资源采样（流畅画质，T-00，固定种子42）：

| 181秒 | 10,659,140 | 46 | 14 | running |

此夹具在中心保持保护并每10秒强制脉冲，累计61次，用于反复销毁/补充实体，峰值敌人24、威胁3；自然玩法高峰由其他测试覆盖。另构造24敌人+96弹丸联合渲染，60次绘制后采样64次draw、9268三角面、49几何、14纹理。单独96弹丸仍一次draw。数据保存在被忽略的`test-results/endless-resources.json`。

这组测试未见持续异常增长，但不是完整GPU显存或稳定60FPS承诺；长模拟是加速执行，不是10分钟真人实机帧率测试。主包约655kB（gzip约170kB），500kB提示仍存在且未隐藏。

实际5180页面以真实键盘事件试玩，未使用生产状态注入：

- 不操作：5.45秒死亡、50分、峰值7敌人/2威胁。
- WASD按固定方向周期绕行，接近威胁且冷却结束时按Space：35.18秒时仍存活、3HP、570分，2次完美和1次擦弹，峰值12敌人/5威胁。此为自动操控，不是人工手感评价，也未证明能绕行无限存活；持续绕行仍有效，应由用户重点试高压后的围堵。
- 两次均无JS异常或性能保护暂停。开局、结算、窄屏、601秒及冲锋走廊截图已查看。首轮试玩曾被开发热更新重置，已丢弃并在代码稳定后重跑，以上数据来自重跑结果。可复核数据为被忽略的`test-results/playtest.json`。

旧`phase-*`与动态难度/渲染性能文档保留为历史记录；当前规则以本文件和README为准。
